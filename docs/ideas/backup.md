# Backup

Status: idea.

## What it does

Keeps the history of logged bottles somewhere outside the browser, so it
survives clearing browser data.

## Why it is interesting

Today the history lives only in the browser. Clearing browser data, or a
work PC being reset, wipes every past day.

## What it would touch

Where the history is stored, and the settings, for a way to save and restore
it.

## Open questions

- A manual export and import file, or saving automatically, for example to
  OneDrive.
- Whether this would ever grow into syncing between devices.
