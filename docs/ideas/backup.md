# Backup

Status: idea.

## What it does

Keeps the history of logged bottles somewhere outside the browser, so it
survives clearing browser data.

## Why it is interesting

Today the history lives only in the browser. Clearing browser data, or a
work PC being reset, wipes every past day. This has happened: Sophie's work PC
clears Edge's site data on restart, the setting is locked by her company, and
asking the browser to keep the data permanently does not stop it.

## What it would touch

Where the history is stored, and the settings, for a way to save and restore
it.

## Open questions

- A manual export and import file, or saving automatically, for example to
  OneDrive. One proposal: Refill saves to a file Sophie picks (Edge's file
  picker), after every change, with an "Open my Refill file" button after each
  restart. It needs the file picker to be allowed on the work PC.
- Whether this would ever grow into syncing between devices.
